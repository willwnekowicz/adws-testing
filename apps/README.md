# Apps

This directory contains application source code organized by deployment target.

## Structure

- **client/** - Client-side code (web frontend, mobile app, desktop app UI)
- **server/** - Server-side code (backend API, services, databases)

## Guidelines

- Keep client and server code strictly separated
- Each subdirectory should have its own package.json, requirements.txt, or equivalent
- Shared code should be extracted to a separate package or library
- Follow language-specific conventions within each subdirectory
