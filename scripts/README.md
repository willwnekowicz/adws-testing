# Scripts

This directory contains build scripts, automation tools, utilities, and deployment scripts.

## Purpose

- Build and compilation scripts
- Development environment setup
- Testing and validation automation
- Deployment and release scripts
- Utility scripts for common tasks

## Guidelines

- Make scripts executable: `chmod +x script-name.sh`
- Include usage documentation at the top of each script
- Use consistent naming: `verb-noun.sh` (e.g., `build-dist.sh`, `deploy-production.sh`)
- Add error handling and validation to all scripts
