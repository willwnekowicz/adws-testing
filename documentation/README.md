# Documentation

This directory contains all project documentation and planning materials.

## Structure

- **research/** - Technical research, competitive analysis, technology evaluations
- **brainstorming/** - Initial ideas, planning sessions, rough drafts
- **specs/** - Formal specifications, requirements documents, design docs
- **implementations/** - Implementation notes, post-mortems, retrospectives

## Guidelines

- Use markdown format for all documentation
- Include dates in filenames for time-based documents (e.g., `research-api-design-2024-01-15.md`)
- Move documents through the lifecycle: brainstorming → specs → implementations
- Keep specs updated as the source of truth for features
